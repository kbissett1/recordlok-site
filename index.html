PROJECT MANAGEMENT FOR THE FIELD

Keep the job site organized.

RecordLok is a mobile project-management application built for construction and field-work projects. It helps users organize project information, document work, coordinate project activity, and keep important job-site information accessible from the field.

What RecordLok does

Project Organization

Keep project information and field activity organized in one mobile workspace.

Field Documentation

Document work and maintain project records while working from the field.

Contractor Coordination

Organize project responsibilities, assignments, and contractor-related activity.

Mobile Access

Access project-management tools from a supported mobile device.

Purchasing RecordLok

RecordLok uses project-based activation. Customers purchase access for an individual RecordLok project.

The current price is displayed clearly inside the RecordLok application before payment is submitted.

Payments are processed securely by Stripe. RecordLok does not directly store customers' complete payment-card information.

Customer Support

Customers needing assistance with RecordLok, project activation, or a purchase may contact support through the public RecordLok support page.

Payments

Payments for RecordLok project activation are processed through Stripe. Successful payment does not rely solely on a browser confirmation; RecordLok verifies activation through its payment system before enabling paid project access.
